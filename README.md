# ⚽ PlayGrid

PlayGrid is a modern Sports Turf Booking Platform that allows users to discover, book, and manage sports turfs seamlessly.

This project is being built as a full-stack portfolio application using modern web technologies with a focus on clean architecture, responsive UI, and scalable development practices.

---

## 🚀 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend (Coming Soon)
- Node.js
- Express.js
- MongoDB
- JWT Authentication

---

## ✨ Planned Features

- User Authentication
- Browse Sports Turfs
- Turf Details Page
- Search & Filters
- Booking System
- Booking History
- User Profile
- Favorites
- Responsive Design
- Admin Dashboard
- Secure REST APIs
